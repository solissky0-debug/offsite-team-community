# 决策摘要模板 / Decision summary template

维护者复制本模板到相关 Discussion 或 Issue，用公开链接串联证据；空项保留“尚无／待确认”，不预填批准。提案人、维护者和审核者可准备材料；**项目发起人保留立项与发布决定权**。本摘要不自动触发执行。

Copy this template into the relevant discussion or Issue. Use public links only, and mark missing evidence as pending. Preparing this summary does not grant approval; the project owner retains task authorization and release decisions.

```markdown
## 决策摘要 / Decision summary

- 日期与整理人 / Date and author:
- 来源 Discussion、自主候选或重复任务 / Source discussion, candidate or existing task:
- 问题、受益者与最小范围 / Problem, audience and minimum scope:
- 已确认依据 / Confirmed evidence:
- 反例、替代方案、风险与待核实项 / Counterevidence, alternatives, risks and unknowns:
- 讨论支持摘要及局限 / Support signals and limits (not verified-member voting):
- 处置 / Disposition: 待补证据 / 暂缓 / 不采用 / 等待立项决定 / 已批准立项
- 原因 / Rationale:
- 项目发起人立项决定与公开证据 / Owner task authorization and public evidence: 尚无 / pending
- 正式 Issue 与任务 ID / Formal Issue and task ID: 尚无 / pending
- 交付与验收标准、依赖 / Deliverables, acceptance criteria and dependencies:
- 认领状态、参与资格核实状态 / Assignment and eligibility verification: 暂停 / on hold
- 报酬 / Compensation: 未约定报酬 / no paid agreement (or public reference to prior terms)
- 内容来源与采用权利 / Sources and incorporation rights:
- 交付 PR、commit 或固定版本 / Deliverable PR, commit or fixed version: 尚无 / pending
- 独立审核人、结论与公开证据 / Independent reviewer, result and evidence: 尚无 / pending
- 项目发起人发布批准 / Owner release approval: 尚无 / pending
- 发布版本、日期与验证证据 / Released version, date and verification: 尚无 / pending
- 未解决事项、下一步与后续更正链接 / Open items, next steps and correction links:
```

支持、立项、独立验收、产品采用和发布分开记录；无需发布的文档评审也应写明“不涉及产品发布”。未采用成果可保留公开讨论及理由，不伪造正式贡献记录。不要公开私人身份材料、资金账户或原始证据。

Record support, authorization, independent acceptance, adoption and release separately. If a document review requires no product release, say so. An unadopted candidate may retain its discussion and rationale without becoming an accepted contribution record. Do not publish private identity documents, financial accounts or raw private evidence.
