# 不在场团队探索版 · OffsiteTeam Exploration

**OffsiteTeam 致力于打造一个让人不受地点限制，在线找工作、组团队、完成项目的工作平台。**

项目目前处于探索阶段，工作交接、共建规则与长期运营方式都需要在小范围实践中验证。当前社区尚无收益，不保证参与回报，也不承诺未来一定盈利或补发奖励。我们会记录经过核验的贡献；贡献记录本身不产生收益权。

[English](#english) · [参与指南](CONTRIBUTING.md) · [任务路线图](ROADMAP.md) · [治理规则](GOVERNANCE.md) · [贡献记录](CONTRIBUTIONS.md)

这里是 OffsiteTeam 的**公开共建资料入口**：我们希望创作者、设计师、开发者、内容与运营伙伴一起提出问题、验证体验、完善平台。

这是资料与协作仓库，不是另一个网站项目。**网站生产源码未在此开放，也未宣布完整开源。**网站功能是否已经可用，以实际产品及已验证记录为准，路线图中的构想不代表已上线。

## 我们希望共同实现什么

我们希望更多人能在网上找到合适的工作和合作伙伴，不受所在地限制地一起完成项目。作品展示、人才发现和协作工具，都是为这个目标服务的。

本仓库是大家一起完善这个平台的入口，不是平台本身，也不代表网站已经实现全部目标。

公开共建先从范围小、可以验证的改进开始。社区贡献与客户商业订单分别管理，不把提建议、提交 PR 或被采用等同于雇佣、股权或收益权。

## 第一次参与

1. 阅读 [参与指南](CONTRIBUTING.md)、[行为准则](CODE_OF_CONDUCT.md) 和 [权利说明](RIGHTS.md)。
2. 在 [Issues](https://github.com/solissky0-debug/offsite-team-community/issues) 提出提案或体验问题；先搜索是否重复。
3. 正式认领前，须在 [OffsiteTeam](https://offsiteteam.work/) 注册并验证邮箱、获得固定 OffsiteTeam 编号，再由维护者核实参与使用的 GitHub 账号与本站账号的关联。编号本身不是身份验证凭证。
4. 等账号验证与关联流程上线、维护者确认范围和验收标准后，再自愿认领。
5. 通过 PR 或 Issue 内可公开的交付物提交；由非提交者审核后记录结果。

**当前状态：正式认领与贡献登记暂待账号流程就绪。** 公开阅读、提案与讨论可以继续；本站邮箱验证、固定编号及 GitHub 关联尚未完成正式环境验收，本仓库没有自动技术门禁。不要在 Issue 中公开邮箱、验证码或账号凭据。

## 当前边界

- 本仓库只开放新写的共建资料和经过审核的公开贡献记录；品牌、用户作品、私人资料不随之开放。
- 当前未批准现金奖励、股权、分红或代币承诺。任何有偿任务都必须在开始前另行明确预算、金额、付款条件和审核人。
- 外部 Issue **尚未接入自动 Codex 执行**；维护者审核后决定是否采纳、分派与执行。写入 Issue 不会自动修改网站。
- 不公开提交密码、验证码、令牌、个人邮箱、用户数据或原始会话日志。安全问题见 [安全说明](SECURITY.md)。
- 许可仍待确认；阅读、提议和 PR 的边界见 [RIGHTS.md](RIGHTS.md)。

## English

**OffsiteTeam aims to be an online work platform where people can find work, form teams and complete projects from anywhere.**

This is an exploratory project. Handoffs, community collaboration and sustainable operations still need validation. The community currently has no revenue. Participation does not guarantee compensation, future profit, retroactive rewards or economic rights. Verified contributions can be recorded without becoming a financial entitlement.

This is OffsiteTeam's public community documentation and collaboration entry point. Creators, designers, developers and operations contributors are welcome to propose improvements and evaluate clearly scoped work.

This repository does **not** publish the production website source code and is not a declaration that the whole product is open source. Roadmap entries describe intentions, not shipped features.

This repository is the entry point for helping build that platform, not the platform itself or a claim that all planned features are available.

Start with the [contribution guide](CONTRIBUTING.md), [code of conduct](CODE_OF_CONDUCT.md) and [rights notice](RIGHTS.md). Public reading, proposals and discussion remain welcome. Before formally claiming a task or having a contribution recorded, participants must register on [OffsiteTeam](https://offsiteteam.work/), verify their email, receive a permanent OffsiteTeam number and have their participating GitHub account association verified. A public number alone does not prove account ownership.

**Formal assignments and contribution registration are on hold until the account process is ready.** Email verification, permanent numbers and GitHub association have not completed production acceptance. This repository does not enforce an automated account gate. Do not post private emails, verification codes or credentials. Once ready, wait for confirmed scope and acceptance criteria before opting in, delivering and receiving review.

The initial tasks cover bilingual terminology, portrait/landscape media presentation and the first-contribution experience. Deliverables use public material or synthetic examples, without private portfolios or production writes; formal participation still requires the account verification described above. External issues are **not connected to automatic Codex execution**.

No cash, equity, revenue share or token reward has been approved for these tasks. Paid work requires separate terms agreed before work starts. Client project payments and community contributions are managed separately. Brand assets and users' work remain outside this repository's contribution scope; a general reuse license has not yet been selected.
