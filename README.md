# 不在场团队探索版 · OffsiteTeam Exploration

**OffsiteTeam 致力于打造一个让人不受地点限制，在线找工作、组团队、完成项目的工作平台。**

项目目前处于探索阶段，工作交接、共建规则与长期运营方式都需要在小范围实践中验证。当前社区尚无收益，不保证参与回报，也不承诺未来一定盈利或补发奖励。我们会记录经过核验的贡献；贡献记录本身不产生收益权。

[English](#english) · [三条参与路径](PROPOSALS.md) · [Discussions](https://github.com/solissky0-debug/offsite-team-community/discussions) · [参与指南](CONTRIBUTING.md) · [任务路线图](ROADMAP.md) · [治理规则](GOVERNANCE.md) · [贡献记录](CONTRIBUTIONS.md)

这里是 OffsiteTeam 的**公开共建资料入口**：我们希望创作者、设计师、开发者、内容与运营伙伴一起提出问题、验证体验、完善平台。

这是资料与协作仓库，不是另一个网站项目。**网站生产源码未在此开放，也未宣布完整开源。**网站功能是否已经可用，以实际产品及已验证记录为准，路线图中的构想不代表已上线。

## 我们希望共同实现什么

我们希望更多人能在网上找到合适的工作和合作伙伴，不受所在地限制地一起完成项目。作品展示、人才发现和协作工具，都是为这个目标服务的。

本仓库是大家一起完善这个平台的入口，不是平台本身，也不代表网站已经实现全部目标。

公开共建先从范围小、可以验证的改进开始。社区贡献与客户商业订单分别管理，不把提建议、提交 PR 或被采用等同于雇佣、股权或收益权。

## 当前边界

- 本仓库只开放新写的共建资料和经过审核的公开贡献记录；品牌、用户作品、私人资料不随之开放。
- 当前未批准现金奖励、股权、分红或代币承诺。任何有偿任务都必须在开始前另行明确预算、金额、付款条件和审核人。
- 参与共建不要求充值、买币或提交钱包地址。
- 外部 Issue **尚未接入自动 Codex 执行**；维护者审核后决定是否采纳、分派与执行。写入 Issue 不会自动修改网站。
- 不公开提交密码、验证码、令牌、个人邮箱、用户数据或原始会话日志。安全问题见 [安全说明](SECURITY.md)。
- 许可仍待确认；阅读、提议和 PR 的边界见 [RIGHTS.md](RIGHTS.md)。

## English

**OffsiteTeam aims to be an online work platform where people can find work, form teams and complete projects from anywhere.**

This is an exploratory project. Handoffs, community collaboration and sustainable operations still need validation. The community currently has no revenue. Participation does not guarantee compensation, future profit, retroactive rewards or economic rights. Verified contributions can be recorded without becoming a financial entitlement.

This is OffsiteTeam's public community documentation and collaboration entry point. Creators, designers, developers and operations contributors are welcome to propose improvements and evaluate clearly scoped work.

This repository does **not** publish the production website source code and is not a declaration that the whole product is open source. Roadmap entries describe intentions, not shipped features.

This repository is the entry point for helping build that platform, not the platform itself or a claim that all planned features are available.

Start with the [contribution guide](CONTRIBUTING.md), [code of conduct](CODE_OF_CONDUCT.md) and [rights notice](RIGHTS.md). Choose one of [three participation paths](PROPOSALS.md#english):

| Path | What you can do | GitHub category or entry |
| --- | --- | --- |
| Evidence-based proposal | Explain a problem, evidence and success criteria; you do not have to implement it | [Ideas](https://github.com/solissky0-debug/offsite-team-community/discussions/categories/ideas) |
| Independent candidate | Display your own small prototype, document or synthetic review without first claiming a task | [Show and tell](https://github.com/solissky0-debug/offsite-team-community/discussions/categories/show-and-tell) |
| Formal task | Review scoped tasks and evidence; formal claiming remains on hold | [Issues](https://github.com/solissky0-debug/offsite-team-community/issues) |

Use [Q&A](https://github.com/solissky0-debug/offsite-team-community/discussions/categories/q-a) for collaboration help and [Announcements](https://github.com/solissky0-debug/offsite-team-community/discussions/categories/announcements) for official updates. These are existing GitHub categories, not a new on-site forum or automatic assignment system.

**Support ≠ task authorization ≠ acceptance ≠ release.** GitHub reactions, comments and polls are feedback, not OffsiteTeam verified-email membership voting or legal-name identity verification. The project owner retains task authorization and release decisions. Displaying an independent candidate guarantees neither adoption, payment nor contribution registration and grants no private source, data or production access.

**Formal assignments and contribution registration remain on hold pending real-user acceptance of the V15 community account process and an explicit opening announcement.** A released entry point does not prove that acceptance has happened. Once open, formal participants must verify their email on [OffsiteTeam](https://offsiteteam.work/), receive a permanent platform number, and have their participating GitHub association verified. A number alone proves no account ownership. GitHub has no automated platform-account gate. Public reading, proposals, discussion and independent displays remain welcome. Never post private emails, codes, credentials, private source or real user data.

Reuse the three initial tasks: [terminology #1](https://github.com/solissky0-debug/offsite-team-community/issues/1), [media presentation #2](https://github.com/solissky0-debug/offsite-team-community/issues/2), and [first contribution #3](https://github.com/solissky0-debug/offsite-team-community/issues/3). Do not duplicate tasks or repositories. An open Issue is not new task authorization or an available assignment. Deliverables use public material or synthetic examples. External content is **not connected to automatic Codex execution**. Trace discussion, authorization, versioned delivery, acceptance and release through the [decision summary](DECISION_TEMPLATE.md).

No cash, equity, revenue share or token reward has been approved for these tasks. Participation does not require deposits, token purchases or wallet addresses. Paid work requires separate terms agreed before work starts. Client project payments and community contributions are managed separately. Brand assets and users' work remain outside this repository's contribution scope; a general reuse license has not yet been selected.
